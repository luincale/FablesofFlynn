# The Fables of Flynn

A read-only mobile chronicle of a D&D campaign — Home, Story, Timeline, Roster, and Places — built as an installable React PWA. Implements the design exported from Claude Design (see `../README.md`, `../chats/`, `../project/`).

## Develop

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
npm run preview
```
